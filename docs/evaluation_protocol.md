# Evaluation protocol (pilot)

## Scenarios
10 pilot scenarios in `evaluation/scenarios/` (generated by `scripts/build_scenarios.py`):

| id | category | expected | key check |
|---|---|---|---|
| s01 | trip_extension | ok | flight + hotel affected, cost ¥1,150 |
| s02 | trip_extension | ok | flight fee/quote missing → cost must be unknown |
| s03 | weather_change | ok | 2 outdoor activities in rain window |
| s04 | weather_change | ok | 1 outdoor activity |
| s05 | place_closed | ok | museum closed, no booking |
| s06 | place_closed | ok | booked venue closed → provider refund −¥180 |
| s07 | transport_delay | ok | cascade within the day, teamLab entry window kept |
| s08 | reservation_change | infeasible | forced slot conflicts with locked dinner |
| s09 | trip_shortening | ok | flight change ¥300 cash, hotel night forfeited |
| s10 | place_closed | infeasible | locked activity at a closed place |

Ground truth fields: `expected_status`, `affected_booking_ids` (bookings that need the traveller to act),
`expected_cost_minor` (or `cost_unknown`), `must_keep` (still-feasible activities that should stay unchanged).

**Please audit the ground truth by hand** before reporting results. Keep the pilot set for development;
build a separate held-out set (target 40 scenarios) for final numbers.

## Fairness
Same model, temperature 0, same facts (trip, bookings incl. policies and quotes, place catalogue with opening
hours, full travel matrix, request), same output schema and cost definition for all LLM methods.
PlanB's LLM sees only the trip/booking/place ids, not the matrix — it does not need them.

## Success definition
- infeasible scenarios: method reports `infeasible` or `needs_information`;
- ok scenarios: status ok **and** zero hard violations **and** preservation = 1 **and** booking set exact
  **and** cost correct (±¥1, or null when the truth is unknown).

## Limitations to state
Small pilot set; simulated data; hand-written ground truth by the system author; travel times synthetic;
one city; results depend on the model and its free-tier availability.
